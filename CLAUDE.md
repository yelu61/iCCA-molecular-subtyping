# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is an iCCA (intrahepatic cholangiocarcinoma) molecular subtype analysis research project. The project identifies and validates three molecular subtypes (C1, C2, C3) through multi-omics data integration and consensus clustering.

A more detailed (Chinese-language) walkthrough of the full pipeline — including formulas, parameter rationale, and per-subtype result tables — lives in [iCCA_Subtype_Analysis_Workflow.md](iCCA_Subtype_Analysis_Workflow.md). Treat this CLAUDE.md as the orientation map and the workflow doc as the reference manual.

Manuscript and figure drafts (`iCCA subtypes, V1, 20260123.docx`, `iCCC subtypes, figures draft.pptx`) plus presentation history (`Meeting/`) are kept at the project root and provide context for how subtype labels and results are framed for publication.

## Analysis Pipeline

The project follows a **strict sequential workflow** across numbered notebooks and directories. Later steps depend on outputs generated by earlier steps.

1. **0-Data/**: Raw and processed data from multiple studies (2012-2025) plus TCGA-CHOL
   - `final/`: Harmonized RNA-seq, DNA-seq, and proteomics data per study
   - Input format: TPM for RNA-seq, variant data for DNA-seq

2. **0-data.ipynb**: Data preparation and integration
   - Filters genes (expressed in ≥20% of samples)
   - Handles batch effects (FPKM→TPM conversion, log2 transformation)
   - Creates `0-Data/0-Data-rnaseq.Rdata` (combined expression matrix)
   - Creates `0-Data/0-Data-rnaseq-microarray1.Rdata` (Illumina microarray validation data)
   - Creates `0-Data/0-Data-rnaseq-microarray2.Rdata` (Affymetrix microarray validation data)

3. **1-Clustering/** and **1-clustering.ipynb**: Consensus clustering to identify molecular subtypes
   - Input: Combined expression matrix from 0-data.ipynb
   - Key outputs:
     - `data/sample_info_with_clusters.xlsx`: Final sample assignments to subtypes C1, C2, C3
     - `data/combined_expr_after_correction.rds`: Batch-corrected expression matrix
     - `deg/`: Differential expression results per subtype
     - `pattern/`: Heatmap visualizations (k=5,6,7 cluster solutions)
     - `drug_sensitivity_results/`: oncoPredict-based drug sensitivity predictions
     - `tme/`: Tumor microenvironment (ESTIMATE/EPIC) analysis results

4. **2-Classfiler/** and **2-classfiler.ipynb**: Classifier building
   - Note: Directory name has typo "Classfier" (should be "Classifier")
   - Builds SVM/Random Forest classifier from clustering results
   - Also includes large-duct vs small-duct iCCA classification using LASSO
   - Output: `data/pred.csv` (classification results)
   - Uses DEG (differential expression genes) from 1-Clustering

5. **3-Proteomic/** and **3-multiomic.ipynb**: Proteomic validation and multi-omics integration
   - Note: The directory is named `3-Proteomic/` but the notebook is `3-multiomic.ipynb`
   - `Subtype_Proteomics_Analysis_Results.xlsx`: Proteomic comparison results
   - `Enrichment_Comparison/`: Pathway analysis comparing proteomics vs transcriptomics
   - Integrates mRNA, protein, and CNV data

6. **4-Validation/** and **4-Validation.ipynb**: External validation using independent datasets
   - Microarray data validation (from 0-Data)
   - CCLE drug sensitivity data with predicted subtypes
   - DepMap expression data for classifier validation
   - Prognostic risk score model (LASSO-Cox)
   - `final_validation_results/`: Validation plots and statistics

## Running the Analysis

### Jupyter Notebooks

The analysis is implemented in R via Jupyter notebooks. Run them in order:

```bash
jupyter notebook 0-data.ipynb
jupyter notebook 1-clustering.ipynb
jupyter notebook 2-classfiler.ipynb
jupyter notebook 3-multiomic.ipynb
jupyter notebook 4-Validation.ipynb
```

**Important execution notes:**
- Notebooks must be run **sequentially** because downstream notebooks load `.Rdata`/`.rds` files produced by upstream notebooks.
- `1-clustering.ipynb` contains long-running cells (ConsensusClusterPlus with 100 reps, NMF with 20 runs). These can take tens of minutes to hours depending on hardware.
- Expression matrices are large (genes × samples). Some visualization cells use `pheatmap` or `ComplexHeatmap` on the full matrix and may be memory-intensive.

### Working Directory

All notebooks assume the working directory is the project root:

```r
setwd("/path/to/202504ZL")
```

Paths throughout the notebooks are relative (e.g., `./0-Data/...`, `./1-Clustering/...`).

## Important Notes

1. **Directory naming**: `2-Classfiler` is misspelled (should be `Classifier`). The notebook is `2-classfiler.ipynb`. Preserve these exact names when referencing paths.
2. **Directory/notebook mismatch**: Step 3 uses directory `3-Proteomic/` but notebook `3-multiomic.ipynb`.
3. **Random seeds** (reproducibility): the dominant seed throughout `1-clustering.ipynb` is `123` (`set.seed(123)` 7×, `seed = 123` 3× including the `ConsensusClusterPlus` call). `set.seed(42)` is used once for classifier training (SVM/RF), and `set.seed(61)` appears once in a single cell. When reproducing the main clustering, use `123`.
4. **Data format**: Expression matrices are **genes × samples** (rows = genes, columns = samples).
5. **Three subtypes**: C1 (metabolic), C2 (immune), C3 (proliferative) — defined by clustering results, not arbitrary labels.
6. **oncoPredict_data/**: Contains drug sensitivity prediction data generated by the oncoPredict R package. Used in clustering subtype characterization.
7. **Microarray validation**: Two separate microarray datasets (`microarray1` = Illumina, `microarray2` = Affymetrix) are created in `0-data.ipynb` and validated in `4-Validation.ipynb`. Source studies for microarray validation include `TIGER-LC` (present in `0-Data/final/` as `TIGER-LC_rnaseq.csv` / `TIGER-LC_sample_info.csv`) alongside `2012Andersen`, `2013Sia`, `2017Jusakual`, and `2020Job`.
8. **Root-level intermediate outputs**: Some results are written to the project root rather than into the numbered step folders — e.g., `sample_info_with_subtype.xlsx`, `sample_info_with_predictions.csv`, `cluster_compare_multiomic.csv`, `single_gene_cox_results.csv`, `single_gene_KM_plots.pdf`. Don't assume an output lives only inside its step folder.
9. **4-Validation external reference files**: `4-Validation/` ships with large input files (DepMap `OmicsExpressionTPMLogp1HumanAllGenes.csv`, `Model.csv`; PRISM `Drug_sensitivity_AUC_(PRISM_Repurposing_Secondary_Screen).csv`; `CCLE_drug_data_with_predicted_subtypes.csv`). These are validation **inputs**, not generated outputs — do not overwrite them. `oncoPredict_data/` similarly contains pre-built `Training Data/` and `GLDS/` subdirectories used as inputs.
